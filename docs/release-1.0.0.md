# Release 1.0.0

The first broad UX reference release expands the earlier law-only draft into a practical reasoning, review and test-planning skill.

Included: 186 source-linked records across five types, 8 article reading routes, a 21-law comparison with UX Design Institute, all 86 active WCAG 2.2 criterion routes, all 30 APG pattern routes at the review date, an offline lookup helper, a reference browser, a review procedure and original-content MIT licensing.

Existing principle IDs and article routes remain stable. The catalog schema is version 2; clients should read `catalog.json` to discover collections and record types rather than assuming a 30-item-only catalog. A WCAG target includes lower levels; exact-level filtering does not.

Checks and actual independent answers are linked in the validation record. No MCP server, model API, visual component library or hosted product is included. Coverage is deliberately stated as named inventories and workflows rather than an assertion that all UX knowledge is finite or universally agreed.
