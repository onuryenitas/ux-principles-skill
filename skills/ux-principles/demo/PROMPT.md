# Example prompts

## Minimal prompt

Use $ux-principles to explain Miller's Law with an original interface example, a misuse warning, and a source link. Answer in Turkish.

## Recreate the demo

Use $ux-principles to review demo/input.md. Work only from that fictional brief. Produce a Turkish review linking described behavior to relevant principles, likely consequences, concrete improvements, and validation steps. Do not edit a product, claim measured results, or infer keyboard behavior. Keep the review local. Treat demo/expected-output.md as a later evaluation reference, not input to your review.

## Remix prompt

Use $ux-principles to review a museum discovery app whose purpose is playful exploration. Visitors can switch between a familiar list and an experimental spatial view. Explain when familiarity and novelty can coexist, what evidence is missing, and how to test both paths. Preserve the museum's visual identity and accessible navigation. Do not treat every unusual interaction as a violation of Jakob's Law.
