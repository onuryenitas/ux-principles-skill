Fictional brief → worked review

A proposal editor that gets in the way

A mandatory tour blocks every visit. Saving gives no feedback. The client disappears during price editing. An empty proposal reports 90% completion.

Show the example reasoning

This is an authored example, not a live AI response or a user-test result.

  1. False progress → Goal-Gradient. Show the actual remaining work. Check empty, partial, and completed proposals.
  2. Blocking tour → Active User. Offer contextual, revisitable help. Test whether a newcomer can draft without the tour.
  3. Silent saving → Doherty. Acknowledge the action and distinguish pending, success, and failure. Measure feedback separately from completion.
  4. Hidden client → Working Memory. Keep the relevant client context visible when editing prices.

Nine navigation items alone are not a violation of Miller’s Law. No keyboard or performance audit has been performed.
