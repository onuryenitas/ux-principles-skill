# Find the relevant UX guidance

Read only the collection needed for the task. All records link to external sources and carry a review date.

## Task routes

| Task | Start here |

| --- | --- |

| Explain a named law | [Principles](principles.json) |

| Review usability broadly | [Heuristics](heuristics.json), then [review method](review-method.md) |

| Check accessibility | [WCAG criteria](accessibility.json), then normative source |

| Implement/test a widget | [Components](components.json), then full APG pattern |

| Design a product flow | [Workflows](workflows.json) |

| Trace article inspiration | [Article routes](articles.json) |

| Determine completeness or compare sites | [Scope](scope.md), [comparison](source-comparison.json), [manifest](catalog.json) |

## Search

Use `scripts/lookup.py` from the skill directory for IDs, words, kinds and WCAG levels. Search is lexical; Turkish workflow keywords are included, but it is not semantic translation. `--target AA` includes A and AA; `--level AA` returns only AA-labelled items.
